10 · TTM Traceable % — Formula

ttpCalcTtmCoordinatePct_() · Supply-weighted coordinate check

CPO TTM %
Pool: SOURCE TYPE = MILL / TRADER / REFINERY (never KCP)
PRODUCT SUPPLY contains CPO — or blank with SUPPLY CPO > 0
Traceable row: valid lat/lng coordinate
Formula: Σ(SUPPLY CPO traceable) ÷ Σ(SUPPLY CPO total) × 100
PK TTM %
Pool: same SOURCE TYPE filter
SUPPLY PK column > 0 (full-year total, not per quarter)
Traceable row: valid lat/lng coordinate
Formula: Σ(SUPPLY PK traceable) ÷ Σ(SUPPLY PK total) × 100
Per-mill shortcut (Monthly Report): mrdMillTtmRowPct_() → 100% if valid coordinate, else 0% (binary per row).

11 · TTP Traceable % — Formula

ttpAggregateTotalTraceablePct_() · Matches sheet footer totals

ProductNumerator (Σ)Denominator (Σ)Display
CPOCPO TRACEABLE VOLUMECPO SUPPLY TO REFINERY#ttp-stat-cpo-traceable
PKPK TRACEABLE VOLUMEPK SUPPLY TO KCP#ttp-stat-pk-traceable
  • Primary method: SUM(numerator) ÷ SUM(denominator) × 100 — same as Google Sheet footer
  • Fallback: if volume columns missing → average of % CPO TRACEABLE or % PK TRACEABLE per row
  • Format: 2 decimal places (e.g. 94.13%) via ttpFormatTraceablePct_()
  • Row filter: ttpIsDataRow_() excludes header echoes and "Total Traceable" footer rows

12 · TTP Sheet — Key Columns & Conversions

Per FFB supplier row in Monitoring TTP/TTM registry

  • Input: FFB SUPPLY to MILL (TON)
  • Conversion: FFB → CPO (20%) · FFB → PK (5%)
  • Output supply: CPO SUPPLY TO REFINERY · PK SUPPLY TO KCP
  • Traceable volume: CPO/PK TRACEABLE VOLUME
  • Per-row %: % CPO TRACEABLE · % PK TRACEABLE
  • Sheet totals: Total CPO % Traceable · Total PK % Traceable
  • Identity: GROUP / COMPANY / MILL / UML ID
  • FFB context: SUPPLIER GROUP/NAME · CATEGORY · LAT/LONG
  • Sync metadata: submission_id · ffb_line_id · synced_at
  • Monitoring preserved on re-sync: MSD · trace volumes · % columns

Category Mix (TTP panel bar)

22 · Validation Rules

Guard rules that prevent data inconsistency

  • Submitted SDD cannot be downgraded to Draft
  • Task List: SCR = submitted AND statusSDD = APPROVED
  • TTP sync: full identity (GROUP/COMPANY/MILL/UML)
  • Supply submit: match_status = matched or new
  • Mill save: formula columns stripped before write
  • EUDR: all enabled criteria must pass
  • Grievance: all 6 indicators required before classification
  • Coordinates: normalizeCoordinate() + recoverCoord()
